🎯 最终推荐：混合方案

推荐公式结构：
雷劫率 = clamp( R_base + V(气血完成率) + 雷劫增幅 + 运气 , 0.15, 0.90 )
心魔率 = clamp( M_base + 0.55×V(神识) + 0.45×V(法力) + 心魔增幅 + 运气 , 0.15, 0.90 )
V(c) = 方案三分段连续曲线（8锚点）

正常突破率 = 1.10 × 雷劫率 × 心魔率

强行突破率 = 正常率 × (1 − 强行惩罚系数 0.15~0.50)
死亡概率 = 白名单制（小境界3% / 大境界8% / 特殊天劫15%上限）

元气：只限制正常突破，低元气允许强行（元气不足惩罚）
