🎯 仙门战争 · 突破方案二：单次总判定制

一次掷骰决定突破成败 ｜ 雷劫/心魔作为加权贡献模块 ｜ 加法聚合避免相乘压缩 ｜ 保底精确可控

📐 核心公式

雷劫贡献 R = h(气血完成率) + 体质修正 + 血脉修正 + 功法雷修正 + 装备雷修正
心魔贡献 M = 0.5×[h(神识完成率) + h(法力完成率)] + 天赋修正 + 命格修正 + 功法心修正 + 装备心修正

突破准备度 D = w雷×R + w心×M
通用基础 G = 0.10 × clamp(D/0.45, 0, 1)　← 按达标比例发放，防零资源+10%下限过高

最终突破率 = clamp( 0.04 + D×S阶段 + G + 外部增幅 + 运气修正 , 0.02, 0.97 )

贡献函数 h(x)：x<1 时 0.45×x2.5　｜　x≥1 时 0.45+0.10×(1−1/x)　｜　封顶 0.55

关键设计：P_floor=4% 统一底线（三项全空仍可搏命）；G 条件化（三项100%才全额10%）；S 阶段系数同时控制难度与压缩大境界超额收益。

📋 落地建议

  • 推荐权重：默认 W1（50/50）起步；若测试显示玩家忽视气血养成，切 W3 动态权重引导大境界前炼体
  • UI 展示：主界面只显示总率；详情面板展开 R/M 贡献条 + 预测瓶颈（"当前心魔薄弱，失败将损失神识法力"）
  • 保底可见：连败计数与下次保底加成对玩家透明，降低挫败感
  • 元气联动：元气不足时禁用正常突破，仅开放"强行"选项并红字警示死亡风险

✅ 方案二优点

  • 单骰不压缩，总率直觉准确
  • 调参/保底/期望次数全部可解析计算
  • UI简单，新手友好
  • 权重系统灵活（三套可切换）
  • 失败仍保留定向归因

⚠️ 方案二缺点

  • 丢失"过雷劫败心魔"叙事中间态
  • 瓶颈判定是补偿机制，非真实两段
  • 加第三关需重构权重而非扩展
  • G条件化稍复杂，需文档说明

🏁 总结

方案二以单次总判定替代双骰连乘，通过 h(x) 凸贡献函数 + 条件化通用10% + 阶段S系数 + 4%底线 四件套，同时满足：资源不足保留极低概率（规则4/5）、超额收益递减、大境界难度断层、元气独立于概率（规则3）。瓶颈判定机制在单骰框架下完整保留了失败归因与定向扣资源能力，死亡严格白名单化（规则11）。若项目优先平衡性与玩家理解成本，方案二是更优解；若优先叙事层次感，回退方案一。
