⚡ 仙门战争 · 突破方案一：双关卡连续概率制

最终成功率 = 雷劫成功率 × 心魔成功率 ｜ 两层独立判定，先抗雷劫后渡心魔，两层都过才算突破成功

📊 核心公式

雷劫成功率 = 雷劫基础率 + g(气血完成率) + 体质修正 + 血脉修正 + 功法修正 + 装备修正 + 运气修正
心魔成功率 = 心魔基础率 + [0.65×g(神识法力均值) + 0.35×g(神识法力最低)] + 天赋修正 + 命格修正 + 功法修正 + 装备修正 + 运气修正
最终突破成功率 = 雷劫成功率 × 心魔成功率

完成率修正函数 g(x)：
  x < 1.0 时：g(x) = 0.45 × x^2.5
  x ≥ 1.0 时：g(x) = 0.45 + 0.10 × (1 - 1/x)
  上限：0.55

⚖️ 优缺点总结

✅ 优点

  • 叙事分离清晰（肉身劫 vs 精神劫）
  • 失败诊断明确，指向具体养成方向
  • 概率曲线连续，全区间非零
  • 增幅作用域独立，无重复计数
  • 可扩展性强，便于加入第三关

❌ 缺点

  • 计算复杂，新手学习成本高
  • 乘法结构导致实际体感成功率偏低
  • 26阶段×2关调参矩阵庞大
  • 元气与概率耦合不足，策略深度有限

📋 方案适用建议

方案一"双关卡连续概率制"最适合追求仙侠叙事沉浸感的项目，特别是希望"雷劫"和"心魔"在玩家心智中形成明确区别的游戏。建议：

  • 在 UI 中明确展示"雷劫成功率"和"心魔成功率"两个独立数值条，让玩家清楚瓶颈所在
  • 失败提示区分"雷劫失败（气血不足）"和"心魔失败（神识法力不足）"
  • 心魔判定采用 C 法（加权平均+短板保护），避免长板完全遮蔽短板
  • 大境界突破前提供"突破预测"功能，显示当前预估的双层概率
