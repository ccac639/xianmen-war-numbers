总览与全局约定

全局数值约定（全文强制）

  • 所有百分比 = 万分比整数，10000 = 100%，10500 = 105%；
  • 所有概率字段统一为 0~10000 整数，禁止浮点存档；
  • 全程 64 位整数运算，每层结算后向下取整；
  • 灵石为 64 位整数（上限 21 亿亿），存档建议十进制字符串。

系统分层总览

  • 境界基础 N → 裸装属性（同阶段统一）；
  • 根骨 / 天赋 / 血脉 / 命格 = 四类角色特质；
  • 神魂 / 身法 / 剑道 / 力量 / 体魄 / 术法 / 御器 = 七维战斗天赋；
  • 功法 / 装备 / 丹药 / 符箓 / 阵法 / 灵兽 = 外部叠加层；
  • 存活率 / 击杀率 / 逃生率 = 动态计算结果，非角色属性。

三组概念边界（正式定义）

  • 根骨 ≠ 体魄：根骨是角色特质（修炼潜力/突破/承载/寿元，出生 1 槽）；体魄是战斗天赋（气血/物防/恢复，可成长）。
  • 炼器 ≠ 御器：炼器是技艺（0~5 阶，生产装备资格）；御器是战斗天赋（法器攻击效率/操控件数/损耗）。
  • 天赋 ≠ 战斗天赋：天赋是角色特质条目（0~3 条被动）；战斗天赋是七维数值体系。

角色天赋系统

4.1 框架规则

数量与品质

  • 品质权重：普通50 / 优秀30 / 稀有15 / 传说4 / 唯一1；
  • 出生 roll：无10%、1条50%、2条30%、3条10%；上限3条。

效果与上限

  • 效果形态：固定值（熟练度）、万分比（效率类）、等级解锁、事件标签；
  • 总量上限：所有天赋对同一属性/玩法合计 ≤ +3000；修炼效率类合计 ≤ +5000。

互斥 / 遗传 / 觉醒

  • 互斥：同互斥组只能一条（天命组 / 厄运组 / 体质组）；
  • 遗传：每条独立 30% 概率传子代；
  • 觉醒：传说品质可通过特定事件觉醒，效果×2，每人一生1次。

血脉系统

5.1 框架规则

来源 / 数量 / 阶段

  • 来源：种族（人族分支/妖族/真灵）＋传承＋事件获得；数量 0~3 条；纯度 1~100；
  • 阶段（纯度＋境界双门槛）：沉睡(<25) → 初醒(≥25) → 大成(≥50＋境界门槛) → 圆满(≥90＋事件)。

战斗加成硬上限

  • 单条 ≤ +3000，全部血脉合计 ≤ +5000；
  • 血脉觉醒特效走独立乘区B，上限 13000（+30%）；
  • 根骨、天赋、命格均不进任何乘区（只进步法加法池），从结构上禁止"血脉×根骨×天赋"连乘。

觉醒条件

  • 境界（如龙裔大成需金丹）＋纯度＋资源/事件（如龙血池洗礼）。

命格系统

6.1 框架规则

生成与变化

  • 出生 roll：凡命(无效果)70%、普通20%、稀有7%、传说/凶3%；每人 1 槽位；
  • 气运：0~100 整数（出生随机 40~60 ＋命格修正），只影响事件，不加战力；
  • 多数永久；可后天转化（双刃完成条件转正向）、污染（事件致凶）、换命（夺舍/天劫/因果，一生1次）。

战斗限制

  • 命格直接战斗加成 ≤ +600；条件型（如道争命）≤ +1000 且仅在满足条件时生效；
  • 对"存活率/击杀率"：只以动态条件进入预测公式（如"天命不灭：本战未被控制时，气血首次归零保留1点"），绝不写成永久百分比字段。

互斥与叠加

  • 互斥组：福星↔厄命；帝王↔天煞孤星；桃花↔孤星；
  • 同标签（气运类）叠加取最高值不累加；不同标签可并存。

6.2 事件概率整数公式

命格事件概率
事件概率 = clamp( 基础概率 + Σ命格修正 + (气运−50)×20 + 技艺等级×300 + 天赋修正, 100, 9900 )

战斗天赋系统（七维）

7.1 评分体系

评分 S ∈ [0,100]

  • 整数；50 = 该境界标准（普通角色）；
  • 出生：均匀随机 20~80；突破大境界时全项 +6；功法/战斗/事件可 +1~3。

软上限与硬上限

  • 有效差值：Δ = min(S,80) − 50 + floor(max(0,S−80)/2)，即 80 以上每点效果减半；
  • 硬上限 S=100。

8.2 总公式与纪律

int64 总公式
最终值 = floor( floor( (基数 + Σ固定) × (10000 + Σ加法池) / 10000 ) × Π乘区 / 10000^(n−1) )
  • 同一属性多来源重复提供：同池相加，跨池相加后统一乘；乘区按固定顺序（功法→血脉→阵法）；
  • 负面效果：只允许进入加法池（负万分比），单属性负池下限 −5000；禁止负乘区；
  • 取整：每层 floor；伤害最终按最低伤害规则处理（≥0 或 ≥1）；概率 clamp；
  • 浮点防御：全程整数；sqrt 类（灵气加速）用查表或整数牛顿迭代；
  • 数值爆炸防御：加法 +20000、乘区积 1.8、最终面板硬上限 = 对应基数的 5 倍（气血 3 倍）——满配极限约裸装 ×5.4，可控。

    8.3 概率与对抗公式（全部整数万分比）

    命中 / 暴击 / 穿透 / 格挡 / 控制 / 吸血 / 反弹
    命中率   = clamp(10000 + 命中修正A − 闪避B, 3000, 10000)

         连续控制衰减：同目标每被控1次，下次控制率−2000（2回合未被控后重置）

反弹     = floor(受到伤害×反弹/10000)，反弹不再触发反弹

    8.4 伤害主公式（混合式，解决 P0 缺项）

    伤害结算链
    防御有效 = floor( 防御 × (10000 − 穿透有效)/10000 )
基础伤害 = floor( 攻击 × 攻击 / (攻击 + 防御有效 × 2) )
减免后   = floor( 基础伤害 × (10000 − 减免有效)/10000 )
格挡成功 → ×5000/10000；暴击成功 → ×暴伤/10000
浮动     = ×(9500 + rand(0,1000))/10000
境界差 d（防守方大境界序号−攻击方，d>0 时）：
  d=1：命中−1000；最低伤害=0（若 攻击<防御有效）
  d=2：命中−3000，伤害×5000/10000
  d≥3：命中−5000，伤害×2500/10000
d=0：最低伤害=1
    结构性优点：同境界时攻、防、气血全部与 N 成正比 → 伤害 ≈ 0.556N、击杀回合数恒定 ≈ 18（含暴击 17.6），落在审阅表要求的 12~18 区间，且与境界无关。

    8.5 成长与玩法公式

    突破 / 修炼 / 技艺 / 生产 / 探索

    8.6 动态存活率 / 击杀率（非角色属性）

    战斗结果动态预测
    D_A = A期望每回合伤害（含命中、暴击、闪避、控制衰减）
K_A = ceil(B有效气血 / D_A)              # A击杀B所需回合
基准胜率R = floor(K_B × 10000 / (K_A + K_B))
先手方：R = min(9500, R + 800)
存活率A = R + (10000 − R) × 逃生率A / 10000
击杀率A = floor(R × (10000 − 逃生率B) / 10000)
逃生率  = clamp(1500 + 身法修正 − 境界差×1500, 0, 7500)

    十二

    验收自检（对照 14 条）

    • 全公式整数万分比实现
    • 不依赖浮点数才能得到正确结果（sqrt 用整数迭代）
    • 无"所有加成直接相乘"设计（加法池＋有限乘区）
    • 根骨、天赋、血脉、命格、战斗天赋职责清晰
    • 技艺不会无条件直接变成战斗力
    • 低境界不能仅靠一个稀有特质稳定碾压高两境界角色（算例②③证明）
    • 高境界仍有明显基础优势（算例①~⑥：2 回合压制）
    • 特殊角色有差异但不因单字段数值爆炸（满配 ≈ 裸装×5.4 有硬上限）
    • 所有最终属性都有软上限或硬上限（见 §8.2+ 速查表）
    • 结果可直接拆成 Godot 数据表与计算模块
    • 无"战斗存活率 +500%"类造成概率超 100% 的表达
    • 概率字段统一说明为 0~10000 整数万分比
    • 未把参考项目高倍率（+200%~+600%）复制到本系统
    • 上传文件规则冲突已全部列出（C1~C9）并给出推荐方案，未擅自隐藏
