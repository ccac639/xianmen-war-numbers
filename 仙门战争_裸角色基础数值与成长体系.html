三、裸角色成长公式

3.1 结算顺序

角色配置校验 → 境界阶段 N → 境界基础面板 → 灵根 / 天赋 / 体质 / 血脉 / 命格有效性确认 → 五维资质计算 → 先天效果聚合 → 裸角色最终面板 → 裸修炼速度 → 裸突破成功率

3.2 境界基础面板

N = RealmN[StageIndex] BaseHP = 10 × N BaseMP = 6 × N BaseATK = N BaseMATK = N BasePDEF = floor(0.4 × N) BaseMDEF = floor(0.4 × N) BaseSpeed = RealmSpeed[StageIndex]

3.3 五维资质

InnateAptitude = 0.30 × SpiritRootScore + 0.25 × TalentScore + 0.20 × InsightScore + 0.15 × BloodlineScore + 0.10 × FateScore RealmFactor = 1 + 0.20 × StageIndex / 25 FinalAptitude = clamp(round(InnateAptitude × RealmFactor), 0, 100)
30/25/20/15/10 及 RealmFactor=1.00～1.20 是已有审查版采用的AI候选口径，不属于六张指定工作表直接给出的总公式。

3.4 裸角色最终战斗属性

FinalCombatStat = floor(BaseRealmStat × (10000 + CombatPctPool) / 10000) + CombatFlatPool

3.5 裸修炼速度

BaseCultivationSpeed: 凡人/炼气 = 10 筑基 = 20 紫府 = 40 金丹 = 80 元婴 = 160 FinalCultivationSpeed = floor(BaseCultivationSpeed × (10000 + CultivationPctPool) / 10000) + CultivationFlatPool

3.6 裸突破

FinalBreakthroughRate = clamp(BaseBreakthroughRate[StageIndex] + BreakthroughFlatPool + BreakthroughPercentPool, 500, 9500)

概率采用0～10000整数万分比；突破成功率表本身仍是AI候选。

四、灵根 / 天赋 / 血脉 / 体质 / 命格

灵根

原始表明确存在 qualificationValue、expAdd 等字段。

qualificationValue → SpiritRootScore → 五维资质30% expAdd / 可解析属性 → EffectPool

当前附件中灵根部分属性ID（如81～88）无法由本批@UnitAttrTmpl完整闭环，因此具体属性效果存在外部映射缺口。

天赋

原始表明确存在 @RoleTalent 具有资质/效果入口，实际数据可见修炼速度、悟性、攻击等效果。

TalentScore → 五维资质25% Talent Effects → EffectPool

血脉

原始表明确存在 @BloodTmpl 使用 addValueId。

BloodTmpl → addValueId → 属性引用解析 → EffectPool BloodlineScore → 五维资质15%

统一BloodlineScore无法由当前附件完整闭环，属于缺少数据，需要人工确认。

体质

原始数据中存在 多个体质记录直接带修炼速度、突破几率、悟性、战斗属性等效果。

Constitution → EffectPool → attribute_growth / combat / cultivation / breakthrough

本轮不增加第六个资质权重，避免破坏既有五维结构。此处为AI候选设计。

命格

缺少数据，需要人工确认 当前附件没有独立命格模板。

StarFateScore + DaoFateScore → FateScore → 五维资质10% Fate Effects → EffectPool
